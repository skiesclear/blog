配置API

由于codex-cli本身使用其他API配置比较麻烦，在headless服务器中使用cc-switch配置又不现实。所以这里使用cc-switch-cli

cc-switch-cli 下载

cc-switch-cli Github

需要科学上网，使用ssh反向代理

配置DeepSeek API

  1. 使用cc-switch打开配置界面
  2. 使用]切换为codex配置
  3. 左侧进入 Providers 界面
  4. 右侧选择a 添加配置,并选择DeepSeek配置添加
  5. 填入API key, 保存退出
  6. 使用[Space] 选用DeepSeek配置
  7. 按[Esc]后，点击P开启路由功能，现在就可以正常使用了

接下来正常使用的时候记得把之前设置的反向代理给取消掉
